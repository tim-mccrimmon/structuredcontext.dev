## SCS v0.3 (Previous)

A previous version of the Structured Context Specification, superseded by
[v0.5.0](/docs/specification/v0-5/).

:::note[Superseded]
SCS v0.5.0 is a breaking change from v0.3 — see the [v0.5 (Current)](/docs/specification/v0-5/)
page and the
[migration guide](https://github.com/tim-mccrimmon/structured-context-spec/blob/main/docs/MIGRATION-0.5.0.md)
if you have v0.3 content.
:::

## What's in v0.3

- Five bundle types (Meta, Standards, Domain, Concern, Project)
- Three SCD tiers (meta, standards, project)
- Bundle import resolution
- Validation framework (loose/strict modes)
- Git-native versioning
- Provenance tracking

## Version history

- **v0.5.0** ([Current](/docs/specification/v0-5/)) — Domain Ontology, any-AI-actor context model, provenance approval
- **v0.3** (Previous) — Bundle type formalization
- **v0.2** — Import resolution
- **v0.1** — Initial specification
