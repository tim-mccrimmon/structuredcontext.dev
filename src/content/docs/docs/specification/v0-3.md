## SCS v0.3 (Previous)

A previous version of the Structured Context Specification. The current version is
[v0.7.0](/docs/specification/v0-7/).

:::note[Superseded]
If you have v0.3 content, migrate in steps: [0.3 → 0.5.0](/docs/specification/migration-0-5/),
[0.5 → 0.6.0](/docs/specification/migration-0-6/), then [0.6 → 0.7.0](/docs/specification/migration-0-7/).
:::

## What's in v0.3

- Five bundle types (Meta, Standards, Domain, Concern, Project)
- Three SCD tiers (meta, standards, project)
- Bundle import resolution
- Validation framework (loose/strict modes)
- Git-native versioning
- Provenance tracking

## Version history

- **v0.7.0** ([Current](/docs/specification/v0-7/)): Agent Skills, Domain repositories, verifiable versions
- **v0.6.0** ([Previous](/docs/specification/v0-6/)): Domain and Project bundles, citations, runtime artifact
- **v0.5.0** ([Previous](/docs/specification/v0-5/)): Domain Ontology, any-AI-actor context model, provenance approval
- **v0.3** (Previous): Bundle type formalization
- **v0.2**: Import resolution
- **v0.1**: Initial specification
